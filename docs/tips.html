学习建议

避坑建议

  1. 先理解再运行。不要只是运行别人的 Notebook，每写一个模块都能手画出数据维度的变化。
  2. 不要囤教程。主线只选一本（LLMs-from-scratch），其余当查阅地图。上面的清单是索引，不是待办。
  3. KV Cache 要亲手实现一遍。它是推理优化的核心，不实现一遍无法真正理解 vLLM 和 Paged Attention 的价值。
  4. 从小模型开始。训练一个 10M 参数的 nanoGPT 比阅读 LLaMA 文档学到的多——小到能在 CPU 上跑，才能随意做实验。
  5. 关注一手来源。HuggingFace、Meta AI、Google DeepMind 的官方博客和代码库永远比二手讲解更可靠。

关于 AI 生成的教程

  • GitHub 上出现大量 "Transformer 教程" 仓库由 AI 批量生成，结构看似完整但常见问题：API 过时、维度计算有误、KV Cache 实现不正确。
  • 它们最有价值的用法是当代码导读工具：用 LLM 对 nanoGPT、LLMs-from-scratch 生成逐行解释，再自己验证每个结论。
  • 判断质量的快速方法：看是否有可运行代码和测试、维度断言是否通过、是否引用原始论文、Issue 区是否有人指出错误。
